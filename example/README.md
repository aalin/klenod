# Klenod Examples

- `web/` contains the framework-style web example with Haml, CSS, assets, routing, watch mode, and an `async-http` server.
- `standalone/` contains a non-web executable bundle example that imports structured data files.
- `box/` contains an experimental `Ruby::Box` example that loads two runtime bundles into separate boxes.
- `performance/` generates a large ignored web-shaped project for build performance testing.
